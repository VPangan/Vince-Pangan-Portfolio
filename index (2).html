  1. #01 CSSWENG · Capstone · 2026 MVP complete

    ExitPass MoPS: a backup app that keeps parking exits running when the main system goes down

    Software engineer, team capstone for an industry client in parking operations

    An Android app for parking operators to use when the facility's central parking system is unreachable. Operators keep processing vehicle exits and capturing payment records on the device, then sync everything back once the connection returns.

    • Built across three tiers: a Flutter app with a local SQLite database (Drift), a Spring Boot REST API secured with JWT, and PostgreSQL running in Docker.
    • Ticket lookups read from a server-side copy of the client's parking data; each exit is saved on the device as unsynced and marked synced after upload.
    • Operators also log incidents, manual gate openings and exception reasons on the device, so nothing is lost during an outage.
    • Traced and fixed two defects before the MVP: API calls missing their auth token, and duplicate captures of the same ticket. Then validated the full flow live, from ticket lookup through sync to updated dashboard metrics.

  2. #02 STSWENG · 2026 In progress

    SeniorChain PH: one nationwide senior citizen ID, verified on a blockchain

    Backend developer, Group 05

    A platform where senior citizens register once and get a single standard ID with a QR code. Approved records are anchored on a blockchain, so establishments can check eligibility without seeing personal details, and duplicate or fake IDs get caught.

    • Spring Boot 4 modular monolith in Java 21, organized with domain-driven design, with role-based access for seniors, local government staff, establishments and government admins.
    • Registration and approval flow done: age checks, duplicate detection with an HMAC of the government ID number, optimistic locking so two staff can't edit one record, ID issuance and an audit log.
    • Approvals write to an outbox table in the same transaction, so requests never wait on the blockchain. The Solidity smart contract is next.
    • 35 automated tests passing, from unit tests to a Testcontainers integration test of the full registration flow.

  4. #04 STADVDB · MCO1 · 2026 Completed Oct 2026

    E-commerce data warehouse that runs reports 100× faster

    Lead author, four-person team; presented the overview and star schema at the defense

    Designed, built and tuned a star-schema data warehouse for about 3.1 million synthetic e-commerce records, with reports shown in a Power BI dashboard.

    • Built a Python ETL pipeline that cleaned messy source data, such as dates in two text formats and product categories under 14 spellings, and loaded a fact table of about 2 million order items.
    • Wrote five OLAP reports covering roll-up, drill-down, slice, dice and pivot, using CTEs, window functions and ROLLUP.
    • The warehouse passed all 24 reconciliation checks against the source and all 26 functional checks.
    • Indexes plus summary tables cut the 15-request benchmark from 88.7 s to 11.5 s, a typical 107× speed-up.
